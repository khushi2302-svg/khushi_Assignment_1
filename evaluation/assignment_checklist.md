# Assignment demonstration checklist

- [ ] Launch Streamlit chat interface.
- [ ] Ask a general question and show a direct response.
- [ ] Ask for current fee status and show the fee tool trace.
- [ ] Ask for scholarship status and show the scholarship tool trace.
- [ ] Ask about failed payment and show retrieved policy chunk.
- [ ] Ask about elective changes and show retrieved policy chunk.
- [ ] Explicitly request a support ticket and show generated ticket ID.
- [ ] Save a non-sensitive programme preference in the sidebar.
- [ ] Restart the app and show that memory persists.
- [ ] Try to save sensitive information and show that the memory guard blocks it.
- [ ] Ask a question not answered by the handbook and show that the agent does not invent policy.
- [ ] Run the evaluation suite and export the CSV.
